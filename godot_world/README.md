# NutriWorld 3D – Godot-Prototyp

Dieser Prototyp ist bewusst getrennt von Flutter. Die Welt besteht aus echten 3D-Objekten: Boden, See, Steg, Bäume und Fische. Die Fische bewegen sich in lokalen See-Koordinaten und können deshalb bei einer späteren freien Kamera nicht auf dem Weg oder am Himmel erscheinen.

## Start

Godot 4.x öffnen und diesen Ordner importieren, anschließend `main.tscn` starten.

WASD bewegt die Kamera. Der Weltzustand wird lokal unter `user://nutriworld_state.json` gespeichert.
