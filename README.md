# Nutrivision 3D World

This project is a Three.js natural scene prototype for the Nutrivision app. It includes a lake, terrain, trees, flowers, rocks, wildlife, fireflies, day/night lighting, stars, and an orbit camera.

## Run locally

1. Install dependencies
   ```bash
   npm install
   ```

2. Start the development server
   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal.

## Features

- Realistic natural island scene
- Water surface with animated waves
- House, trees, flowers, and grass
- Fish and firefly animations
- Day/night cycle with sun and moon
- Stars and constellations
- Orbit camera for changing the angle of view
- Shadowed lighting and atmospheric tone mapping

## Stack

- Vite
- Three.js
- OrbitControls
